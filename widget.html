Widget Lockin 🔥

Tes 150 derniers jours de gym sur ton écran d’accueil, avec ta streak.

  1. Installe l’app gratuite Scriptable (App Store).
  2. Tape Copier le script ci-dessous.
  3. Ouvre Scriptable → + en haut à droite → colle (tiens ton doigt → Coller).
  4. Tape le titre « Untitled Script » en haut et renomme-le Lockin, puis Done.
  5. Tape le script Lockin pour le lancer → connecte-toi avec ton compte Lockin.
  6. Sur ton écran d’accueil : tiens ton doigt → Modifier → Ajouter un widget → Scriptable → taille moyenne → Ajouter.
  7. Tiens ton doigt sur le widget → Modifier le widget → Script : Lockin.
